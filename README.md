# Laundry Mart – Login Page

A simple and clean login page for Laundry Mart, created using HTML and CSS. The design features a split layout with a washing machine illustration on the left and a login form on the right.

## Features

- Split-screen login page layout.
- Custom washing machine illustration.
- Email and password input fields.
- Forgot Password link.
- Login button.
- Register Now link.
- Clean typography and styling.

## Technologies Used

- HTML5
- CSS3
- Flexbox
